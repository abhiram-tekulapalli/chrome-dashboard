# Aura Ultra Premium

Aura Ultra Premium is a sleek and modern Chrome extension that replaces your default New Tab page with a premium, glassmorphism-inspired dashboard designed for focus, productivity, and style.

It offers a polished browsing experience with a live clock, personalized greetings, quick access shortcuts, a todo list, notes, a pomodoro timer, and customizable themes and backgrounds.

## ✨ Features

- Beautiful glassmorphism UI
- Live clock and personalized greeting
- Quick search integration
- Customizable shortcut links
- Task list for daily productivity
- Scratchpad / notes area
- Pomodoro timer with focus and break modes
- Light and dark theme support
- Custom background support
- Export, import, and reset data options

## 🚀 Installation

1. Download or clone this repository to your computer.
2. Open Google Chrome and navigate to `chrome://extensions`.
3. Enable "Developer mode" in the top-right corner.
4. Click "Load unpacked".
5. Select the folder containing this extension.
6. Open a new tab and enjoy Aura Ultra Premium.

## 🛠️ Project Files

- `manifest.json` - Extension configuration
- `index.html` - Main UI layout and styling
- `app.js` - Extension logic and interactivity

## 📌 Usage

- Use the new tab page as your daily productivity hub.
- Add or edit shortcut links for your favorite websites.
- Manage tasks and notes directly from the dashboard.
- Switch themes and backgrounds to personalize the experience.
- Use the data tools to backup or reset your saved settings.

## 🔒 Privacy

This extension stores your preferences and saved content locally in your browser. It does not require any external service to function.
